4. Event Loop: tasks vs microtasks

      
Guess the output order first, then run it. Rule: run sync code → drain all microtasks → take one macrotask → repeat.

  .then(() => console.log('3 microtask: then A'))
  .then(() => console.log('4 microtask: then B'));
